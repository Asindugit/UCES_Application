# Student Course Enrollment System

A Java-based Student Course Enrollment System developed using **Java** and **NetBeans IDE**. The system is designed to manage student information, course information, and student course enrollments.

The application uses **text files for data storage** instead of a database such as MySQL.

---

## 📌 Project Overview

The Student Course Enrollment System is a desktop application developed to simplify the management of students, courses, and course enrollment records.

The project demonstrates practical Java programming concepts, including Object-Oriented Programming, file handling, data management, input validation, and application logic.

All application data is stored locally using text files, so the system does not require a database server.

---

## ✨ Features

- Add and manage student information
- Add and manage course information
- Enroll students in courses
- View student information
- View course information
- View enrollment information
- Store application data using text files
- Read and write data from text files
- Validate user input
- Manage application records
- Simple and user-friendly interface
